# Every query value, in every line: the access logs keep the query string,
# which can carry a token or a credential (ntfy takes one as ?auth=).
[?&][^=&\s"\\]+=([^&\s"\\]+)
# ModSecurity rule messages quote the value that matched, which can be a
# password or a cookie, in the operator text and in [data] (whatever format a
# rule logs). Each group ends at the text ModSecurity writes after it, because
# the value can hold spaces, ' and ]; ModSecurity writes " as \x22.
\(Value: `(.*?)' \) \[file "
\[data "((?:.*?[^\\])?)"\] \[severity "
